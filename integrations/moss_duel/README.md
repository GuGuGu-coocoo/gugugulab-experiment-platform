# Historical preassembled reference

This directory contains the earlier, already wired Moss Duel example. It is
retained for its existing regression tests and engineering evidence. It is not
the generic GEC download and is not used in the manual integration exercise.

Start with the independent game under `examples/moss_duel/`, install the generic
package under `packages/gec_godot/`, then create your own entry scene and script
using [the manual guide](../../docs/moss_duel_gec.md).
