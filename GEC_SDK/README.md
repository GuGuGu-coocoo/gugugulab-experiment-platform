# GEC SDK

English · [中文](readme_zh.md)

Source for connecting a Godot project to GEP:

- [gec_godot/](gec_godot/): Godot runtime, session helper and export packaging scripts.
- [gec_web/](gec_web/): browser storage, upload and Godot bridge.

Start with the [GEC integration guide](../docs/gec_godot_en.md) to build and install the dependency package. This source folder is not an install-ready Godot addon; the packaging tool assembles the project layout and required dependencies.

For a hands-on exercise, follow the [clean game integration walkthrough](../docs/moss_duel_gec_en.md).
