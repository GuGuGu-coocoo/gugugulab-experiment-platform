# 实验开发者说明

实验科学逻辑继续通过通用数据模块记录事件/checkpoint并结束任务，固定release/session和本地待上传数据不随新配置重新绑定。本轮后台修复不改变事件协议、原生存储格式或科学任务。

Web托管与预览统一使用维护者配置的GEP_PUBLIC_API（含非默认端口）；原生的connection.json仍是开发/兼容路径。GEC统一准入/恢复/收尾壳、按冻结配置动态切换参与方式，以及完整原生下载套件是下一批目标，不能假定当前API已提供。

当前接入及构建见[启动指南](quickstart.md)与[协议](protocol.md)。不开发通用Runner；刺激、随机化、试次与科学时序由实验负责。
