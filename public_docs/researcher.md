# 研究者操作说明

仅供合成测试。参与模式与招募状态显示已保存值。名单每行一个ID，密码模式使用标准CSV两列：`001,"synthetic,password-long"`；密码至少12字符，含逗号用双引号包围。ID保留前导零，整批存在重复或错误时不导入；成功会显示新增数量，不显示密码。账号管理页还提供有界 XLSX 模板与导入：用户与权限模板（create/update/disable/enable，已有账号必须写明当前版本，导入永不重置或覆盖已有密码，create 默认发出一次性邀请）与名单模板（仅追加，已有 ID 永不覆盖；文本 `001` 原样保留，数字形式 ID 被拒绝，不会猜测前导零）；上限 2 MiB、展开 10 MiB、1000 行、32 列，公式、宏、外部关系链接、稀疏远端单元格与超界声明维度被整体拒绝，表头或其他工作表的公式同样拒绝，逐行错误不执行任何行。名单密码在预览时立即哈希到私密暂存，预览、会话、Cookie、日志与导出都不含明文或哈希；暂存绑定完整内容，提交成功后立即清除，过期未确认的暂存由有界清理路径移除。

招募选择后立即提交；暂停/关闭均拒绝新参与，已有有效会话仍按原窗口上传。已有批准发行后政策冻结，不能据此修改旧发行。原生发行不显示网页入口；登记了程序归档的原生构建在批准时生成平台完整包，可在发行列表下载并与 `connection.json` 一起分发（该配置已随包冻结，解包后直接启动，无需替换文件）；只登记描述、不提供程序归档的旧兼容路径仍不提供平台下载。macOS arm64 与 Windows x64 使用同一套流程：macOS 程序归档是整个 `.app`，Windows 程序归档是包含 EXE、PCK、原生依赖与 GDExtension 清单的程序根目录；Windows 描述必须显式声明程序根、入口、依赖与清单，服务端按声明的名字核对真实 PE x86-64 映像与 PCK 版本，不要求任何固定程序名。

公开门户与当前发行（03C 工程版，03D 起平台感知）：研究页可单独勾选“公开到参与门户”，并填写公开简介、预计时长与设备要求；公开只改变门户展示，不改变参与模式、名单或招募。必须显式选择“当前发行”，可以是本研究已批准且带已发布 Web 包的发行，也可以是已批准且带平台完整包的完整原生发行；只登记描述、没有程序包的原生发行不可选。切换只对新参与生效，旧会话、待上传、恢复、下载、配置与已发布包保持原发行。门户按平台呈现：Web 当前发行提供浏览器开始入口；完整原生当前发行显示独立程序（Windows x64 或 macOS arm64）参与说明，不生成 `/run/.../web/index.html` 路径，也不把受控的完整包下载变成门户公开下载——完整包仍只在持有 build 权限的账号内下载；原生完整包缺失或被篡改时门户失败关闭，不显示任何开始入口。过期研究发布版本提交会被拒绝且不写入，变更写入前后审计。公开门户只列出“公开 + 招募中 + 有效当前发行”的研究；私有不因开放招募而公开；已结束研究默认不显示，需显式勾选才显示无开始按钮的简介。稳定研究入口为 experiment origin 的 `/join/<study_id>`；点击“开始参与”会带着页面观察到的发行与发布版本经过平台入口校验，页面过期时显示“研究入口已更新”并要求刷新，不会加载旧版本应用或创建旧发行新会话；刷新后按新发行进入。旧直达 `/run/<release_id>/…` 不带该绑定时仍按原准入契约保留，不会重定向到新发行。

创建固定快照后可下载JSONL、CSV和metadata.json；元数据不包含records。撤权后旧链接同样拒绝。无权限操作不显示或说明原因，后端仍检查权限。表单拒绝显示错误，不代表保存成功。

账号权限页（/users）已实现实例权限矩阵：先勾选研究可见性，再展开显式动作；取消可见性会同时清除子权限，服务端拒绝“不可见却保留子权限”的矛盾提交。普通 Admin 只能授予自己“有效且可委派”的动作，且目标账号必须在自己可支配的范围内，不能借矩阵取得 Owner 角色权力；Owner 行对所有账号（包括 Owner 本人）只读，Owner 修改自己的密码使用“修改我的密码”自助入口。新增显式动作 identity_mapping.read（查看具体名单身份与会话对应，不含答案）与 session.view；它们不会自动补授给任何已有账号，只能显式分配。所有矩阵、冲突收敛与 Excel 导入都先预览、再用本人密码一次性确认：预览绑定操作者、操作内容、输入摘要与当前治理/目标版本，过期或任何相关变化都会整批拒绝且零部分写入；重复提交同一成功预览是幂等的，但会重新核对当前角色、研究范围、目标接管条件与强制改密状态，操作者被停用、降权、被撤销研究权限或目标权限提高后不再返回旧结果。Owner 由实例指针唯一决定，可任命或降级 Admin；Admin 可以管理非 Owner 账号（含其他 Admin 的改密、停用与启用），但操作者不能重置、停用或启用拥有自己无法支配研究权限（含不可委派权限）的账号，也不能自行提升角色。新账号可通过邀请（本人设置密码，24 小时内一次性有效）或一次性临时密码创建；临时密码首次登录必须改密，改密、重置或停用会使旧登录会话失效。账号治理操作需重新输入操作者密码、校验并发治理版本并写入脱敏前后审计，一次性密钥只显示一次、不进入审计或导出。权限审计按动作保存“是否授予 / 是否可委派”的完整布尔差异，因此只调整可委派标记也有记录。缺少 study.view 的旧授权子权限被视为矛盾：不自动扩大可见性，由 Owner 在预览后显式选择补 view 或移除冲突子权限；接口、浏览器页会拒绝并提示。

公开研究列表、公开政策与稳定研究入口已交付 03C 工程版；统一 GEC 参与壳与完整冻结原生包已交付 03D 工程版（macOS arm64 完整包已在真实程序上完成合成工程闭环；Windows x64 已实现平台契约、真实交叉导出与本机冻结包工程闭环，Windows 实机执行与验收未运行，原设计者自主体验与独立 T17 仍未运行），后台信息架构与完整门户（03E）仍待实现。名单 Excel 导入已在 /users 交付（同时保留研究页 03A CSV 兼容路径）。先完成工程修复及原设计者自主体验，再按[独立研究者验收](researcher_acceptance.md)安排T17；当前不用于真实研究。
