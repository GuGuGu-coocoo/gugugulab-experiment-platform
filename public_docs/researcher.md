# 研究者操作说明

仅供合成测试。参与模式与招募状态显示已保存值。名单每行一个ID，密码模式使用标准CSV两列：`001,"synthetic,password-long"`；密码至少12字符，含逗号用双引号包围。ID保留前导零，整批存在重复或错误时不导入；成功会显示新增数量，不显示密码。Excel模板和预览导入尚未实现。

招募选择后立即提交；暂停/关闭均拒绝新参与，已有有效会话仍按原窗口上传。已有批准发行后政策冻结，不能据此修改旧发行。原生发行不显示网页入口，完整原生包下载尚待实现；现有连接配置仅为开发/兼容流程。

创建固定快照后可下载JSONL、CSV和metadata.json；元数据不包含records。撤权后旧链接同样拒绝。无权限操作不显示或说明原因，后端仍检查权限。表单拒绝显示错误，不代表保存成功。

账号权限页（/users）已实现：Owner 由实例指针唯一决定，可任命或降级 Admin；Admin 可以管理非 Owner 账号（含其他 Admin 的改密、停用与启用），但只有 Owner 能任命或降级 Admin，且操作者不能重置、停用或启用拥有自己无法支配研究权限（含不可委派权限）的账号，也不能自行提升角色。新账号可通过邀请（本人设置密码，24 小时内一次性有效）或一次性临时密码创建；临时密码首次登录必须改密，改密、重置或停用会使旧登录会话失效。账号治理操作需重新输入操作者密码、校验并发治理版本并写入脱敏前后审计，一次性密钥只显示一次、不进入审计或导出。缺少 study.view 的旧授权子权限被视为矛盾：不自动扩大可见性，由 Owner 在预览后显式选择补 view 或移除冲突子权限；接口、浏览器页会拒绝并提示。

统一GEC参与壳、门户与名单Excel导入尚未交付。先完成工程修复及原设计者自主体验，再按[独立研究者验收](researcher_acceptance.md)安排T17；当前不用于真实研究。
