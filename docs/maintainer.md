账号权限采用显式版本路由：旧实例扩展数据库后仍保持 v1；新建合成实例明确使用 v2。未知版本拒绝授权，不降级为旧规则。新增稳定账号主体 UUID，旧审计保留引用，历史研究创建者无法确定时保持空值。账号永久删除已实现（工程版，人工测试尚未进行）：/users 的红色入口要求操作者当前密码、目标用户名逐字确认与当前治理版本，同一事务内重新认证、鉴权、整账号接管比较并写审计；Owner 行、自删与超出范围拒绝，删除不可恢复，登录账号/密码资料/权限/登录会话、绑定该用户名的待接受邀请与该账号发出的邀请和恢复签发全部失效，其创建的研究、被试、会话/事件与历史审计保留，历史审计显示“已删除账号 + 稳定主体 UUID”，审计写入失败整笔回滚。删除的同一事务还会把仅存 user 外键的历史审计按确切 actor 回填稳定主体，不按用户名猜测；邀请在签发时绑定已有账号的稳定主体（新行 identity_version=2），全新账号申请以邀请自身 UUID 为独立申请身份，删除后新邀请不能仅靠相同用户名接管旧权限。旧仅用户名绑定的未消费邀请在删除时失效；旧哈希与旧邀请的既有边界保持不变。

旧实例切换 v2 前必须先在新的合成副本演练。Owner 在 `/users` 查看逐账号、逐研究的权限差异，对缺失授权、未来研究默认及不完整审计证据逐条选择，再预览最终策略。确认时输入本人密码；服务器重新核对策略、版本与授权，在同一事务内保存覆盖规则、切换版本、失效旧邀请与待确认预览并写审计。任何失败全部回滚，重复确认不会重置权限。缺少旧授权不代表同意扩大权限。
