# Moss Duel：苔境决斗

一个独立的 2D 单 Boss 动作小游戏。你有 5 点生命，使用轻击、蓄力重击、冲刺和弹反，击败拥有两阶段的苔境守卫。角色、场景和视觉效果由代码原创绘制，音效使用免费开放的 Kenney CC0 素材，来源见 [素材声明](THIRD_PARTY_NOTICES.md)。

## 打开并运行

1. 打开 **Godot 4.7.2 标准版**。
2. 在项目管理器点击“导入”，选择本目录的 `project.godot`，点击“导入并编辑”。
3. 等待资源导入完成，点击编辑器右上角的 ▶“运行项目”。
4. 游戏打开后，点击 **Enter the arena**，或按 Enter 开始。

本项目没有安装 GEC，也没有服务器连接或账号配置。直接运行即可玩。

## 操作

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或 ← / → |
| 跳跃 | 空格、W 或 ↑ |
| 冲刺 | E |
| 轻攻击 | 点按 J 或鼠标左键 |
| 重攻击 | 按住 K 或鼠标右键蓄力，再松开 |
| 弹反 | 点按 L 或 Shift |
| 暂停 / 继续 | Esc 或右上角 Pause 按钮 |
| 音效开关 | 右上角 Sound 按钮 |

轻击动作结束后才能再出招。重击可以直接点按；按住约 0.8 秒后松开，伤害更高。蓄力时移动较慢，适合在 Boss 攻击后的恢复空档使用。

## 看懂 Boss 的提示

- **金色提示**：横扫或突进，可以弹反。在攻击即将命中时点按 L / Shift；成功窗口为 160 毫秒。成功会反击并让 Boss 硬直，此时可以追加攻击。
- **红色地面提示**：地震，不能弹反。跳起避开，或移到冲击范围外。
- **冲刺**：短时间无敌，可以穿过攻击；有冷却，不能无限连续使用。
- **半血后**：Boss 进入第二阶段，节奏变快。阶段转换会先给你一个安全空档。

不要看到金色提示就立刻弹反：先看 Boss 蓄势，接近命中时再按。画面下方会显示当前攻击、弹反与恢复提示。

击败 Boss 或耗尽生命后，这一局结束，界面显示用时、弹反次数、攻击次数和受伤次数。点击 **Another duel** 或按 Enter 可以开始新的一局；暂停不会丢失当前动作。

## 手动加入 GEC

先确认独立版可以正常开始、攻击、暂停和结束，再按 [手动接入 GEC 指南](../../docs/moss_duel_gec.md) 操作。该指南提供需要复制的代码、文件位置和检查步骤。

本游戏用于测试游戏接入和 GEP 操作流程；它没有提供经研究协议验收的科学计时或研究结论。
